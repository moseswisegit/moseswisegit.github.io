# moseswisegit.github.io

Portfolio personnel de Moïse Agbossaga — architecte logiciel et développeur Full Stack & Mobile.

Site en ligne : https://moseswisegit.github.io/

## Structure

```
.
├── index.html          Page unique (sections : hero, à propos, compétences, projets, expérience, contact)
├── assets/
│   ├── css/style.css   Styles (variables CSS, sections, responsive)
│   ├── js/main.js      Animation de frappe, dépliage des cartes, reveal au scroll
│   └── img/            Favicon et autres visuels
└── README.md
```

Pas de build : le site est publié tel quel par GitHub Pages (branche `main`, racine).
Ouvrir `index.html` directement dans un navigateur suffit pour prévisualiser en local.

## Mettre à jour

- **Contenu** (projets, expérience, compétences) : modifier directement les sections correspondantes dans `index.html`.
- **Styles** : `assets/css/style.css`.
- **Comportement** (animations, interactions) : `assets/js/main.js`.

Chaque changement de contenu ou de comportement est commité séparément, avec un message décrivant le *pourquoi* du changement, pas seulement le *quoi*.
